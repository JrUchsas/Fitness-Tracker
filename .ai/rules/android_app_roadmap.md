# Future Android App Roadmap & USB Debugging Rules

- **Planned Architecture**:
  - Backend: Laravel 12 REST API (`/api/v1`) using Laravel Sanctum for bearer token auth.
  - Frontend: Cross-platform **Flutter** (Dart) Android App with dark glassmorphic theme matching web design.
- **Testing Setup**:
  - Live Testing: USB cable debugging connected to physical Android device via `adb` / `flutter run`.
  - Emulator: Android CLI screenshots and automated `php artisan test` API endpoints.
- **Status**: Discussed and saved for future implementation upon user request.
